BFS 응급환자 이송 및 의료 접근성 시뮬레이터

실행 방법
1. ZIP 파일의 압축을 풉니다.
2. index.html과 img 폴더가 같은 위치에 있는지 확인합니다.
3. index.html을 Chrome, Edge 등 웹 브라우저로 엽니다.

사용 방법
- '환자 위치' 도구를 선택하고 격자를 클릭해 출발점을 지정합니다.
- '병원 추가' 도구로 병원을 추가할 수 있습니다.
- '도로 차단' 도구로 통행 불가 도로를 설정하거나 해제합니다.
- '지우기' 도구로 병원이나 장애물을 제거합니다.
- '한 단계 진행' 또는 '자동 재생'으로 BFS 과정을 확인합니다.
- 'BFS 전체 실행'으로 결과를 바로 확인할 수 있습니다.

모델 가정
- 10x10 격자형 도로 지도
- 상하좌우 이동만 가능
- 모든 도로의 이동 비용은 동일
- 장애물 칸은 통행 불가
- 병원은 여러 개일 수 있으며, BFS에서 가장 먼저 도달한 병원을 선택

주의
교육용 단순화 모델이며 실제 응급의료 이송 경로·의료기관 선택에 사용하면 안 됩니다.
